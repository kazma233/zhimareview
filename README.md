# zhimareview

基于 [MyGo](https://mygo.egoist.dev)（Go 原生 UI，GPU 绘制）的单窗口多 tab git 查看工具。核心动机是**同时看多个目录**：每个 tab 自带目录选择，选定一个目录后递归扫描其中所有 git 仓库；tab 条自绘在标题栏区（`TitleBarHidden` 保留红绿灯），多项目像浏览器一样共存；再次启动应用 = 已有实例的窗口带到前台（单实例锁）。

专注「看」：改动、diff、历史、远程状态；暂存可做，提交交给外部工具完成。

## 功能

### 多 tab 工作区

像浏览器一样把多个项目放进一个窗口，每个 tab 是一个互不干扰的独立工作区。

- 浏览器式 tab 条自绘在标题栏区（保留红绿灯），整条可拖动、双击最大化
- 拖动 tab 调整顺序：拖过目标后落在其拖动方向的一侧，悬停目标时显示插入线；超宽滚动时在可见范围内拖动
- 双击标签内联重命名（Enter/失焦提交、Esc 取消），右键菜单也可进入；右键「颜色」子菜单给标签设预设色，底部色条标记
- 悬停 tab 显示工作区全路径、仓库数量、改动数量和错误标题
- 「＋」新建选择态 tab，× 或 Cmd/Ctrl+W 关闭；最后一个 tab 关闭后回到选择态，不退出应用
- 重启恢复：窗口位置由 `StateKey` 记住，上次打开的项目 tab（顺序、名称、颜色）与激活项从 `session.json` 恢复（tab 内查看状态不恢复；diff 的查看偏好从 `config.json` 恢复）
- 单实例：再次启动应用把已有实例的窗口带到前台，不开第二个窗口

### 选择即工作区

tab 的起点是选一个根目录，选完即进入工作区开始递归扫描。

- 系统目录对话框 + 最近目录列表（JSON 持久化，最多 50 条）
- 最近目录有序号展示、宽度 640，超出高度滚动

### 聚合改动侧栏

一个根目录下可能有几十个仓库，侧栏把它们折叠成一棵按目录层级组织的改动树，一眼看清哪里有改动。

- 改动按「已暂存 / 未暂存」两组连续排列，组标题可折叠并显示计数；untracked 归未暂存，空组不显示
- 组内按目录层级折叠或在平铺列表间切换；干净仓库不再显示为空节点（仓库总数见顶栏）
- 文件名按状态着色：M 橙 / A、U 绿 / D 红 / R、C 天蓝；目录继承子孙最重状态并显示数量
- 点击行高亮跟随，侧栏重建后选中不丢

### 全局搜索

搜索范围是当前工作区的**所有仓库**，不只是当前仓库。

- 输入即时搜文件名/目录名（含未跟踪文件）
- 回车搜文件内容（`git grep`，不分大小写、子串匹配、跳过二进制，每仓库上限 200 行）
- 点击文件/内容命中打开文件，点击目录命中切到目录列表并展开到位；清空恢复原侧栏列表
- 搜索框支持标准文本编辑快捷键（Cmd/Ctrl+C/V/Z 等）

### diff 视图

基于 MyGo 官方 `editor.DiffView` 看改动，并可按块还原。

- 行内词级高亮、折叠未改动上下文（默认前后 3 行，点击分隔条展开）、统一/分栏切换、内置查找条
- 图片改动旧/新两版并排对比（各带尺寸·大小信息；新增/删除单侧时单图占满），支持 PNG/JPEG/GIF/WebP/BMP；其他二进制文件明确提示
- 图片可缩放查看：滚轮/捏合缩放（新旧两列联动）、拖拽或触控板双指平移、双击重置回适配；打开即聚焦，方向键平移、`+`/`−` 缩放、`0` 重置
- 查看偏好是全局的：展开未修改、目录入口的「查看 diff」、统一/分栏各只有一个值，显式切换即写入 `config.json`，所有 tab 与重启后共用
- 逐 hunk 落盘还原：只还原选中的块，未跟踪文件还原即删
- 侧栏列表行右键：文件可暂存/取消暂存，目录可暂存整个目录，仓库行可暂存整个仓库，均可复制绝对路径与名称

### 提交历史

全部引用可达的提交在一个列表里，选一条看完整补丁。

- 时间倒序，左列短哈希 + 引用徽标 + 标题 + 作者日期（作者/日期列固定宽、单行截断）
- hover 列表行显示完整提交信息（可换行）与全部分支
- 右侧详情按文件逐段渲染补丁（保留 git 的 hunk 边界与原文件行号）
- 列表行右键：复制完整 hash、`git revert`（合并提交禁用，悬停有提示）
- 按提交标题 / 作者 / 完整或短 hash 搜索：首次搜索加载该仓库完整历史后本地过滤

### 远程操作

不用切终端就能确认远程状态。

- 提交历史页对当前仓库 `fetch`（`--all --prune`）与 `pull`（默认 `--ff-only`，勾选 `rebase` 后 `--rebase`；复选框 hover 有策略说明）
- 仓库下拉切换当前仓库：选中项一行显示「仓库名 · 当前分支/ahead-behind」（分支灰色），每个选项也显示各自的分支与状态、当前仓库带「当前」标记——切换前即可看到上下文
- 顶栏「全部 fetch」并发拉取工作区所有仓库，进度模态逐仓库显示等待/fetch 中/完成/失败与总进度条；失败仓库的错误正文直接在模态内展开，可一键复制；运行中再次点击「全部 fetch」重开进度模态，关闭模态不取消后台 fetch

### 目录模式与文件查看

不看 git 状态时，按磁盘真实文件浏览。

- 真实文件树按需懒加载（跳过符号链接），目录聚合改动状态色，行右键可复制绝对路径与名称
- 文件点击只读查看：按扩展名 per-language 语法高亮、行号，打开即聚焦（方向键/查找直接可用）；图片直接预览（滚轮/捏合缩放、拖拽平移、双击重置、方向键平移、`+`/`−`/`0`）；二进制明确提示
- Markdown 预览：CommonMark + GFM，本地图片按文件目录解析；diff 与文件查看双入口，预览/源码开关切换，按钮文案不随状态跳变

### 准实时刷新与错误处理

外部工具改了文件，打开中的视图自动跟上。

- `WatchFiles` 递归监听（Debounce 50ms/MaxDelay 500ms 批次，避开 Windows 监听快照上限），按路径提示刷新打开中的 diff/文件与受影响仓库；`.git` 与依赖目录排除防回环减噪；仓库增删另有 15s 兜底扫描
- 所有失败以模态呈现：pull / 单仓库 fetch / revert / 暂存 / 读取 / 监听走错误弹窗，正文保留 git 的多行原始提示，可滚动、一键复制完整错误信息；「全部 fetch」的失败在进度模态内展开，模态已关时回落错误弹窗
- 错误归产生它的 tab：普通错误未读时 tab 上有红点标记；「全部 fetch」的失败在进度模态内展示，关闭模态即视为已读，不再点红点

## 安装与运行

```bash
go tool mygo dev      # 开发（热重载）
go test ./...         # 测试（internal/git 用真实 git 夹具，视图用 ui.NewTester 无窗口断言）
go tool mygo vet      # 框架侧检查
go tool mygo build    # 构建（build/<platform>/ 下产出可执行与安装物，macOS 为 .app + dmg）
task install          # 构建并安装到当前用户（见 Taskfile.yaml）
```

## 显式偏差

- **diff 上下文**：官方 diff 视图折叠未改动的上下文行（默认前后 3 行，点击分隔条展开）。
- **聚焦**：打开任何内容（文本/图片/diff）都自动把键盘焦点送进内容区，无需先点一下；滚轮/触控板始终跟随指针位置（命中即滚，与浏览器一致）。
- **heic 图片**：不支持（MyGo `DecodeBitmap` 支持 PNG/JPEG/GIF/WebP/BMP）。
- **链接**：Markdown 链接可选中/复制，点击行为按官方组件默认（http/https/mailto 打开）。
- **提交**：不做提交功能；侧栏列表行右键可暂存/取消暂存，提交由外部工具完成。
- **pull 策略**：默认只允许快进（`--ff-only`），历史分叉时报错而不自动 merge；需要变基时勾选 `rebase`（`--rebase`）。
- **提交搜索**：首次输入搜索词时一次性加载当前仓库全部提交（`git log --all`），之后本地过滤；超大仓库首次搜索需要等待完整历史传输。
- **搜索结果快照**：全局搜索结果是发起搜索时的数据快照，之后工作区变化（扫描/监听刷新）不会自动更新结果；要看最新状态需重新搜索。
